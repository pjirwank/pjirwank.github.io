# Website editing guidance

This is a static HTML/CSS/JavaScript website with no build step. Keep all five navigation pages and local links working. Preserve publication IDs when sorting, the grouped publication sections, individual BibTeX files, and PDF links. Do not display empty publication sections. Keep animations looping without pause controls. Project 2 is 1x and Project 4 is 0.5x speed.

The owner has requested privacy: do not enable GitHub Pages, change repository visibility, or deploy publicly unless explicitly requested. Preview locally on 127.0.0.1. Do not add hosting credentials or tokens to this repository.
